# Генрих Будильник 1.0 ⏰

Простой офлайн-будильник на Android: выбираешь время, аудиофайл в папке телефона, и каждый день в это время играет твоя песня.

## Функции

- Выбор времени через системный Time Picker, формат 24 часа.
- Выбор своего MP3/аудиофайла через системный проводник Android (Storage Access Framework, ACTION_OPEN_DOCUMENT).
- Сохранение доступа к выбранному файлу после перезагрузки.
- Ежедневный **точный** будильник `AlarmManager.setAlarmClock`.
- Работа без интернета и без сервера.
- Повторная постановка будильника после перезагрузки или обновления приложения.
- Музыка повторяется до отключения на экране или в уведомлении.
- Проверка звука и отдельная кнопка остановки.
- Если файл недоступен, попытка воспроизвести системный звук будильника.

**Ограничения MVP:** один ежедневный будильник, без отдельных дней недели и без функции «отложить». Если устройство принудительно останавливает приложение, некоторые прошивки Android могут не доставлять будильник до повторного запуска. Не полагайтесь на тестовую сборку как на единственный критически важный сигнал пробуждения, пока не проверите её на своём телефоне.

## Сборка в Android Studio

1. Откройте эту папку как проект.
2. Дождитесь синхронизации Gradle и установки Android SDK 35 (если Studio предложит).
3. `Build > Build APK(s)`.
4. Результат: `app/build/outputs/apk/debug/app-debug.apk`.

Нужны Java 17 и Android Gradle Plugin 8.7.3; Gradle 8.10.2.

## Сборка без компьютера, через GitHub Actions

1. Создайте **приватный** репозиторий GitHub с веткой `main`.
2. Распакуйте архив и загрузите **содержимое** папки `GenrihAlarm` в корень репозитория (включая скрытую `.github/workflows`). GitHub не распаковывает ZIP автоматически.
3. Откройте вкладку **Actions** → **Build Android APK** → **Run workflow**.
4. После успешного запуска зайдите в результаты и скачайте артефакт **GenrihAlarm-debug-apk**.
5. Распакуйте архив артефакта на Android и установите `app-debug.apk`. Разрешите установку приложений из этого источника, если телефон спросит.

На iPad в Safari можно управлять GitHub Actions, но загрузка папок с вложенной структурой из мобильного браузера может быть неудобной. Альтернатива: Android Studio на ПК или работа с репозиторием через Git-клиент.

## Разрешения и особенности Android

- `USE_EXACT_ALARM`: приложение именно будильник, поэтому использует точные сигналы. Подробнее: https://developer.android.com/develop/background-work/services/alarms
- `POST_NOTIFICATIONS`: необходим для удобного уведомления и кнопки выключения на Android 13+.
- `USE_FULL_SCREEN_INTENT`: для экрана будильника на заблокированном устройстве; на Android 14+ может требоваться отдельное разрешение.
- `FOREGROUND_SERVICE_MEDIA_PLAYBACK`: воспроизведение музыкального сигнала, когда приложение не открыто.
- `RECEIVE_BOOT_COMPLETED`: повторное включение будильника после перезагрузки.

Выбирайте **локальные аудиофайлы**, а не потоковые облачные треки, которым может требоваться интернет.

## Тестирование

1. Установите приложение и дайте разрешение на уведомления.
2. Выберите MP3, нажмите «Сохранить и включить».
3. Проверьте, что выбранный трек воспроизводится кнопкой «Проверить звук» и прекращается кнопкой «Остановить звук».
4. Поставьте время на 2–3 минуты вперёд, заблокируйте экран и проверьте срабатывание.
5. Перезагрузите телефон и повторите проверку.
6. Если полноэкранный экран не появился на Android 14+, нажмите кнопку настройки соответствующего разрешения в приложении.

## Конфиденциальность

Приложение не использует интернет, не имеет разрешения на доступ ко всей памяти, не отправляет файлы и не содержит аналитики. Оно получает доступ только к выбранному пользователем аудиофайлу.
